Conexión

Configurar el bot

  1. En Telegram abra @BotFather, envíe /newbot y copie el token.
  2. En el archivo .env: TELEGRAM_ENABLED=1 y TELEGRAM_BOT_TOKEN=…
  3. Ejecute python bot_telegram.py y envíe /id a su bot.
  4. Ponga ese número en TELEGRAM_CHAT_IDS (varios separados por coma).
  5. Reinicie la aplicación, el receptor y el bot, y envíe el mensaje de prueba.

Un NOC donde la IA asesora y las personas deciden

El sistema recibe mensajes Syslog de equipos Cisco, Fortinet y Huawei, los clasifica y aplica seis políticas de seguridad antes de que un asistente de IA los analice. Las acciones de impacto siempre requieren la aprobación de un analista, y cada decisión queda en la auditoría.

Cómo se ejecuta

  1. iniciar_noc.batInstala y abre todo con doble clic (Windows)
  2. admin + TOTPDoble factor RFC 6238: QR y códigos en el README
  3. python app.pyAplicación web en 127.0.0.1:5000
  4. python receptor.pyRecibe Syslog por UDP 5514
  5. python simulador.pyEnvía 20 eventos de prueba
  6. python bot_telegram.pyBot de consulta (opcional)
  7. python -m pytest -qPruebas automáticas
